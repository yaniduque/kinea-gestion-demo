# Kinea Gestión · Demostración pública

Esta carpeta contiene una demostración **estática e interactiva en memoria**. Todo el contenido mostrado es ficticio; no contiene código de autenticación, secretos, conexiones a base de datos ni información clínica real. Las fichas, citas y borradores creados durante la sesión solo viven en el navegador y se eliminan al recargar la página.

La publicación está pensada exclusivamente para explicar los módulos de Kinea Gestión a potenciales clientes.
